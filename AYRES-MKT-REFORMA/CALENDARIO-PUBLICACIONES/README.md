# Calendario de publicaciones AYRES

Calendario organizado a partir del plan maestro de visibilidad y marketing orgánico.

## Estructura

- `01-PLAN-ORGANICO`: todas las publicaciones en una sola carpeta, ordenadas cronológicamente.

Cada carpeta se llama `AAAA-MM-DD-tipo-contenido` (ej.: `2026-08-24-reel-03-fawna-vs-old-prince`), así el listado alfabético coincide con el orden de publicación y el nombre dice qué contiene. Reorganizado el 24/08/2026 (antes existía `00-ESTA-SEMANA` separada y carpetas `DD-MM-26-día` sin descripción).

Cada carpeta contiene `PUBLICACION.md` (ficha con estado, evidencia, copy y métricas) y, cuando la pieza está terminada, los archivos publicables.

## Estados

- `LISTO PARA PUBLICAR`: contiene el archivo final.
- `PENDIENTE DE CREAR EN INSTAGRAM`: requiere stickers o armado manual de Stories.
- `PENDIENTE DE PRODUCCIÓN`: el guion está definido, pero falta la pieza final.
- `CONDICIONADO`: requiere filmación o autorización interna.
- `EN ESPERA DE MÉTRICAS`: depende de los resultados de publicaciones anteriores.
