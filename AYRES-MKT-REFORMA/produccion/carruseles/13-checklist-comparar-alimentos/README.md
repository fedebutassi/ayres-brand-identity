# Carrusel 13 — Checklist para comparar alimentos

Carrusel educativo de 7 placas en formato 1080 × 1350 px.

Los valores, ingredientes y presentaciones se cargan desde `infoproductos/productos.json`. Los envases provienen de los recortes reales del proyecto.

## Regeneración

```bash
node AYRES-MKT-REFORMA/source/carrusel-13-checklist/render.cjs
```
