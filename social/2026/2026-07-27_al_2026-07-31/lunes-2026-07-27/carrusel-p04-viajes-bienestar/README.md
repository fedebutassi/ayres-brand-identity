# P04 — Checklist para viajar seguro con tu mascota

- Fecha de publicación: 27/07/2026
- Formato: 9 placas de 1080 × 1350 px
- Categoría: Viajes / Bienestar
- Objetivo: convertir la preparación y el traslado en una lista práctica de seguridad

## Render

```sh
node render.cjs
```

Los PNG finales se guardan en `output/`. Para renderizar una placa individual:

```sh
node render.cjs 4
```

Las fotografías fueron generadas específicamente para esta pieza mediante la
herramienta integrada de generación de imágenes. No contienen texto, logos ni
productos comerciales; toda la identidad de AYRES se compone en HTML/CSS.
