# Reel — Cachorro y alimento adulto

Formato 1080 × 1920, 30 FPS, duración aproximada 16 s. La zona de contenido deja márgenes conservadores para la interfaz de Reels.

1. `node render.cjs`
2. `zsh build-video.sh`

El MP4 final no incluye audio. Para publicación orgánica puede sumarse audio original o música autorizada desde Instagram.
